# EMS
Employee management system is a simple web application with very limited functionalities in its current state that I have built to "practice" in my spare time. The reason for my choice to keep it simple is the short hiatus I took from development due to my university studies. 

The app itself was made using ReactJS and Bootstrap for the frontend and SpringBoot for the backend that connects to a mySQL database following REST architecture. Using simple Bootstrap elements found in their documentation sums up the design of a straightforward and responsive GUI.
